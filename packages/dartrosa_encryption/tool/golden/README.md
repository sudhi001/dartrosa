# Encryption golden fixtures

Inputs and generator for `test/src/golden_fixtures.dart`, the byte-exact
outputs of ODK Collect's submission encryption that the tests compare
against. See the docstring of `generate.py` for how to regenerate them.

## Test-only key pair

`test_private_key.pem` and `test_public_key.b64` are a **test-only RSA
key pair**, generated for these fixtures and published on purpose so that
anyone can reproduce and decrypt the golden outputs. The key protects
nothing:

- never use it to encrypt real submissions or configure it in a real form;
- secret scanners flagging `test_private_key.pem` can ignore it (it is a
  known, public test fixture).

## Third-party content

- `forms/` holds ODK Collect test forms, unmodified (Apache-2.0, see the
  package `NOTICE`).
- `Golden.java` re-implements ODK Collect's `EncryptionUtils` logic on
  the JVM (with Bouncy Castle and kXML 2.3.0 from the local Gradle cache,
  not redistributed here).
- `case*_input/` are DartRosa's own synthetic sample submissions
  (`photo.jpg` is generated bytes, not an image).
